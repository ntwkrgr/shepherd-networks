# Network Performance & Security Bundle

**Service Type:** Recurring Monthly
**Price:** $150/month
**Status:** Active offering

---

## What's Included

- Everything in Network Monitoring (see separate note)
- Everything in DNS Security (see separate note)
- 1 hour of remote support per month for questions, tweaks, or minor configuration changes
- Support hour does **not** roll over month to month — use it or lose it

## Value Proposition

Monitoring ($75/mo) + DNS Security ($25/mo) purchased separately = $100/mo. The bundle adds an included support hour for just $50 more — well below the standard $95/hr consulting rate.

## Ideal For

- Small businesses that want a hands-off, all-in-one managed network package
- Homeowners with more complex setups who want ongoing peace of mind
- Anyone who wants a single monthly bill covering monitoring, security, and support

## How It Works

1. Initial setup of monitoring and DNS security (included)
2. Monthly recurring billing via card-on-file
3. Client can use up to 1 hour of remote support each month for questions or minor changes
4. Monitoring alerts are reviewed and triaged; client is notified of issues
5. Monthly health summary provided

## Commitment

Month-to-month or annual billing available. No long-term contract required.
