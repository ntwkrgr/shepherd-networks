# Troubleshooting & Optimization

**Service Type:** Hourly, On-Site
**Price:** $95/hr (2-hour minimum)
**Status:** Active offering

---

## What's Included

- Network performance assessment and speed testing
- Wi-Fi interference analysis and channel optimization
- Router and switch configuration review
- Bandwidth management and Quality of Service (QoS) tuning
- Connectivity issue diagnosis and resolution
- Security audit and firmware update review

## Ideal For

- Anyone experiencing slow, unreliable, or intermittent network issues
- Businesses where network problems are affecting productivity
- Clients who've tried the "reboot the router" approach and it's not cutting it
- Anyone who wants a professional review of their existing network setup

## How It Works

1. I arrive on-site and assess the current state of the network
2. Run diagnostics: speed tests, interference analysis, configuration review
3. Identify root causes and implement fixes on the spot where possible
4. Provide recommendations for any issues that require follow-up (e.g., equipment upgrades, cabling changes)
