## Service Description

Provider will design and/or install an IP-based security camera system for Client's property, including site assessment, camera placement planning, equipment selection, and full system configuration.

## Project Phases

1. **Consultation** (free) — Discuss needs, goals, and property layout
2. **Site Assessment** — Walk the property, recommend camera types, placement, and quantities
3. **Equipment Recommendations** — Provide a list with pricing and sourcing guidance
4. **Client Equipment Purchase** — Client procures equipment
5. **Installation & Configuration** — Provider installs, configures, and tests the full system
6. **Walkthrough** — Demonstrate live feeds, recording review, and system management
