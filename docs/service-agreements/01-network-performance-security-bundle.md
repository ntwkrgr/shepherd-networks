## Service Description

The **Network Performance & Security Bundle** is a comprehensive managed network service combining continuous monitoring, DNS-based security, and monthly remote support into a single package.

### Included Services

1. **Network Monitoring (24/7)**
   - Uptime and availability monitoring for routers, switches, and access points
   - Wireless performance metrics: signal strength, client load, channel utilization
   - Proactive alerting when devices go offline or performance degrades
   - Monthly summary report of network health and trends

2. **DNS Security**
   - Managed secure DNS resolution for the client's entire network
   - Blocks malicious domains, phishing sites, and known malware infrastructure
   - Custom filtering rules tailored to the client's needs
   - Network-wide protection — no software required on individual devices
   - Ongoing rule updates, allowlist/blocklist adjustments, and configuration changes

3. **Remote Support (1 Hour/Month)**
   - Up to 1 hour of remote support per month for questions, configuration tweaks, or minor changes
   - Support hours do **not** roll over from month to month
   - Sessions are scheduled by mutual availability, typically during evenings or weekends
