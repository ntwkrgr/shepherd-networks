# DNS Security

**Service Type:** Recurring Monthly
**Price:** $25/month
**Status:** Active offering

---

## What's Included

- Managed secure DNS resolution for the client's entire network
- Blocks malicious domains, phishing sites, and known malware delivery infrastructure
- Custom filtering rules tailored to the client's business or household needs
- Network-wide protection — no software to install on individual devices
- Delivered via managed DNS providers compatible with most hardware
- Ongoing management: rule updates, allowlist/blocklist adjustments, configuration changes

## Ideal For

- Any home or business that wants an extra layer of security without per-device software
- Families wanting content filtering and safe browsing
- Businesses concerned about phishing, malware, and employees visiting risky sites

## How It Works

1. I configure the client's router/gateway to use a managed DNS service
2. Custom filtering profiles are created based on client needs
3. All DNS queries on the network are filtered — malicious and blocked domains are stopped before a connection is ever made
4. I manage the configuration ongoing: adjusting rules, adding exceptions, updating as needed

## Commitment

Month-to-month or annual billing available. No long-term contract required.
